## 📌 Overview

**Amazon Clone** is a full-featured e-commerce application designed to replicate core functionality of Amazon. The application features full product browsing, basket state management, user authentication, and secure online checkout powered by **Stripe**. 

Built with **React** and **Firebase**, it delivers a fast, responsive user experience with real-time database updates and persistent shopping cart management.

---

## 🛠️ Core Technologies

- **Frontend:** React, React Context API / Redux, React Router
- **Styling:** CSS3 / Tailwind CSS
- **Backend & Authentication:** Firebase Authentication, Firestore Database, Firebase Cloud Functions
- **Payment Processing:** Stripe API & Webhooks
- **Deployment:** Firebase Hosting / Vercel

---

## 💫 Application Features

- 🛒 **Interactive Product Catalog:** Browse products with rating systems, descriptions, and dynamic pricing.
- 🛍️ **Shopping Cart & State Management:** Add/remove items with real-time subtotal calculation.
- 🔐 **User Authentication:** Secure email/password login and registration powered by Firebase Auth.
- 💳 **Stripe Checkout Integration:** Complete end-to-end payment processing with real-time card validation.
- 📜 **Order History & Management:** Store and view past orders tied to authenticated user accounts.
- 📱 **Fully Responsive Layout:** Optimized user interface across desktop, tablet, and mobile devices.
